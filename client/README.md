# 📊 Sales Analytics Dashboard

A full-stack analytics dashboard that provides insights into sales data using interactive visualizations.

## 🛠 Tech Stack

* Frontend: React, Chart.js
* Backend: Node.js, Express
* Data: CSV processing
* Deployment: Render, Netlify

---

## ✨ Features

* 📊 Total sales KPI
* 📈 Top products (Bar chart)
* 🥧 Category-wise sales (Pie chart)
* 🔍 Product search
* 🎯 Category filter
* 💡 Business insights

---

## 📂 Project Structure

```
client/   → React frontend  
server/   → Express backend  
```

---

## ⚙️ Installation (Local Setup)

### Backend

```
cd server
npm install
node server.js
```

### Frontend

```
cd client
npm install
npm start
```
